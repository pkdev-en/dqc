📦 Hex Export — Casio Bitmap

💡 Copy rồ dán vào máy Casio hoặc pixel editor

❓ Hướng dẫn sử dụng P2B Pro

① Chế độ Ảnh → Hex
Dùng tab Ảnh → Hex ở sidebar:
- Kéo thả ảnh, Ctrl+V dán ảnh, hoặc nhấn Chọn ảnh
- Chỉnh vị trí, kích thước, threshold, invert, sharpen
- Dùng Adjustments & Filters để xử lý ảnh trước khi threshold
- Bấm Xuất Hex đề lấy hex (copy / download .txt)
- Định dạng: space-separated hex bytes, mỗi dòng = 1 row
② Chế đỘ Hex → Ảnh (Dịch hex)
Dùng tab Hex → Ảnh ở sidebar:
- Dán hex (space-separated, v.d. 00 FF 00 FF) vào ô text
- Điền Width và Height nếu cần (tự động tính nếu đủ số byte)
- Bấm Dịch hoặc Ctrl+Enter để xem bitmap
- Dùng Invert và Threshold để lọc ảnh
- Có thể Ctrl+V trực tiếp hex từ bất kỳ đâu, tool tự động nhận diện
③ Auto-detect
Khi bạn nhấn Ctrl+V:
- Nếu clipboard có ảnh → tự động chuyển sang chế độ Ảnh → Hex
- Nếu clipboard có text dạng hex (nhiếu cặp hex phân cách bằng space) → tự động chuyển sang Hex → Ảnh và dịch luôn
④ Thử thuật
- Canvas mặc định 192x63 (màn hình Casio)
- Dùng Dither để giảm số màu trước khi threshold
- Remove BG dùng edge detection để loại nền
- Export hex dạng space-separated, tương thích với pixel editor của VECF

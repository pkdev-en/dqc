🔧 ROP Compiler
Assembly SH-3 → Hex
Nhập ASM và nhấn "Compile"...
Hướng dẫn:
• setlr — gadget name → hex (4 bytes)
• pop er0,rt — gadget name → hex
• hex FD 24 30 30 — raw hex passthrough
• call ffff — BL call (4 bytes)
• er0=er8,pop er8,rt — any gadget name
• org D730 — set base address
• label: — define label
• adr_of label — label address (2 bytes)
